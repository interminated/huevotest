# HUEVO.SU — «Насколько ты долбоёб?»

Полностью готовый шуточный квиз для браузера: 15 ситуаций, 4 варианта ответа, результат 0–100%, шесть уровней вердикта, анимации, адаптивный дизайн и PNG-карточка для репоста.

## Запуск

Требуется Node.js 18 или новее. Никаких npm-пакетов устанавливать не нужно.

```bash
npm start
```

Откройте `http://localhost:3000`. Для другого порта задайте переменную окружения `PORT` (например, `PORT=8080 node server.js`).

## Размещение на BotHost

1. Загрузите **содержимое этой папки**, сохранив структуру `public/`.
2. Тип проекта: Node.js. Главный файл: `server.js`. Dockerfile не нужен.
3. Если хотите сайт по домену, включите «Использовать домен» в настройках BotHost и настройте его там.
4. Запустите проект. Сервер сам использует порт из `process.env.PORT`, если хостинг его задаёт; иначе 3000.

Тест можно также разместить как статический сайт: для этого достаточно содержимого `public/` без Node-сервера.

## Изменение контента

- Вопросы, ответы и баллы: `public/app.js`, массив `QUESTIONS`.
- Уровни результатов: `public/app.js`, массив `LEVELS`.
- Внешний вид: `public/styles.css`.
- Тексты и разметка: `public/index.html`.

Счёт: сумма баллов ответов (0–3 за вопрос) / максимум × 100, округлённая до целого. Это не настоящая психологическая оценка.

## Как устроено

- Пользовательские ответы сохраняются временно только в localStorage устройства, чтобы можно было продолжить после обновления страницы.
- Результат не отправляется на сервер, база данных и регистрация не нужны.
- Кнопка «Поделиться» использует системный диалог обмена при его наличии либо копирует текст и ссылку.
- «Скачать карточку» рисует PNG 1080×1350 в браузере через Canvas.
- Звук выключен по умолчанию; включается отдельной кнопкой и генерируется в браузере.
- Шрифты Google Fonts загрузятся при наличии интернета; без них используются системные аналоги.

## Рекомендация для домена

Если `huevo.su` уже содержит другой сайт, лучше разместить этот проект на отдельном поддомене (например, `test.huevo.su`) либо интегрировать папку `public` в существующее приложение. Не заменяйте содержимое действующего сайта без резервной копии.
